# Assignment 1: Web Application Development (SPI 2201)

This repository contains a responsive and feature-rich member registration web application developed as part of the Web Application Development coursework at Kirinyaga University. Built using modern HTML5, CSS3, and vanilla JavaScript, the application features comprehensive client-side form validation, dynamic DOM manipulation for real-time member registration and removal, live error-clearing handlers, an active member counter, and a persistent dark mode toggle interface.
